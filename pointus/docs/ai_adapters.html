Configuring AI providers

The Magic Pointer AI in Pointus is supported by using your own API credentials or local models. Below are configuration instructions for each of the supported providers.

Google Gemini

Cloud
  1. Visit the Google AI Studio API Keys page.
  2. Sign in with your Google Account and click Create API Key.
  3. Select an existing Google Cloud project or generate a new one, then copy the key.
  4. Check the Gemini Model Documentation to verify the latest model IDs.
Setting Field Recommended Value / Example
API Key AIzaSy...
Preferred Model(s) * gemini-2.5-flash, gemini-2.5-pro
* Google regularly updates Gemini aliases and preview tags. Faster, lower-latency multimodal releases may become available—verify the latest IDs on Google AI Studio.

OpenAI

Cloud
  1. Navigate to the OpenAI API Keys Dashboard.
  2. Sign in, verify your phone number if prompted, and ensure you have an active prepaid balance in Billing.
  3. Click Create new secret key, set your permissions, and store the token safely.
  4. See the OpenAI Models Overview for specific snapshot and alias names.
Setting Field Recommended Value / Example
API Key sk-proj-...
Preferred Model(s)* gpt-4o-mini, gpt-4o
* OpenAI releases frequent point updates and snapshot snapshots. Review the OpenAI model catalog to substitute lighter, newer endpoints as they become available.

Anthropic Claude

Cloud
  1. Go to the Anthropic Console API Keys page.
  2. Sign in or create a developer account, and make sure credits are added under Billing.
  3. Click Create Key, name it (e.g., Pointus), and copy the resulting string.
  4. Review the Anthropic Models Guide for current generation identifiers.
Setting Field Recommended Value / Example
API Key sk-ant-api03-...
Preferred Model(s)* claude-3-7-sonnet-latest,claude-3-5-haiku-latest
* Using the -latest suffix automatically points to Anthropic's current stable build, but newer model families may supersede these. Check the Anthropic documentation for newly launched models.

xAI (Grok)

Cloud
  1. Visit the xAI Cloud Console.
  2. Log in with your X/xAI account and configure a payment method.
  3. Head to the API Keys tab and click Create API Key.
  4. Consult the xAI Model Documentation for available model endpoints.
Setting Field Recommended Value / Example
API Key xai-...
Preferred Model(s)* grok-beta, grok-vision-beta
* xAI endpoints and beta aliases change rapidly as newer Grok generations exit training. Inspect the xAI docs for active production identifiers.

Ollama

Local / Private
  1. Download and install Ollama from ollama.com.
  2. Start Ollama on your machine or private server. By default, it listens at http://localhost:11434.
  3. Pull any model you want to run locally via your terminal (e.g., ollama run llama3.2 or ollama pull mistral).
  4. Check the Ollama Model Library for all supported local model tags.
Setting Field Recommended Value / Example
Host Endpoint http://localhost:11434
Preferred Model(s)* llama3.2:latest, mistral:latest
* Local model availability depends entirely on the models you have pulled locally. Check the Ollama library for lightweight quantized weights optimized for low-latency desktop execution.
